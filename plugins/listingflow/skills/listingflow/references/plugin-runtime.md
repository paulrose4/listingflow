# 插件运行检查

仅在本机首次使用、环境改变或运行能力缺失时读取本页。保持运营只填 SKU、站点和资料的入口，不把这些步骤变成运营操作。

1. 以当前已加载的 `SKILL.md` 所在目录为 Skill 根目录，不回退到开发者的个人 Skill，也不假设插件缓存名或版本号。
2. 当前环境提供 `load_workspace_dependencies` 时先调用它，使用返回的 Python 绝对路径；没有该工具时检查现有 Python 3.12+，不猜开发者路径。
3. 运行 `PY -X utf8 -B SKILL/scripts/listingflow.py doctor`。逐项检查 `result.packages`，不能只凭外层 `ok: true` 判定依赖齐全；`MISSING` 或导入失败都表示能力缺失。
4. 所需依赖和规则包正常时直接继续。Node 与 Excel 图片预览是可选能力，预览不可用不能误报双 Excel 无法生成，也不能声称已看过预览。
5. 需要 Excel 图片预览且环境给出 Node 和模块目录时，仅在当前子进程设置 `LISTINGFLOW_NODE`、`LISTINGFLOW_NODE_MODULES`，不改系统环境。
6. 必要运行库确实缺失时，给运营一句影响说明，并给发布负责人列出缺失项、Python 版本和 Skill 版本；不要求运营执行命令，不静默安装依赖。经用户授权且有受管安装路径时才由开发配置独立环境。
7. 单独检查当前可用的浏览器或连接器。`doctor` 不证明浏览器、eBay 登录、PLA 权限或联网调研已经成功；按关键词调研流程分别记录实际尝试及结果。
8. 输出写到获准的独立可写目录，不能写进插件安装缓存或产品原件目录。不读取没有获准的资料目录。

本页不授予安装依赖、访问新目录、登录店铺或刊登权限。公司规则仍需真实业务批准。
