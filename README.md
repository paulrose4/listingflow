# ListingFlow 商品文案助手

为电商运营核对产品资料，生成 eBay 英文或德文文案，交付 `文案.xlsx` 和 `自查.xlsx`。默认结果为运营审阅草稿，不自动刊登或代替业务批准。

## 首次安装

发布负责人确认仓库已上传并完成试装后，按以下步骤操作：

1. 打开 Codex 的插件页面，选择“添加插件市场”。
2. 来源填写 `https://github.com/paulrose4/listingflow`。
3. “Git 引用”和“稀疏路径”留空，点击“添加市场”。
4. 找到“ListingFlow 商品文案助手”，点击安装。
5. 新建任务，选择已安装的 ListingFlow。不要继续使用安装前的旧任务来判断安装结果。

私有仓库需要读取权限。如果提示仓库不存在或无法读取，请联系发布负责人，不要自行公开仓库。运营无需运行终端命令。

## 日常使用

填写下面三项即可。目录必须是当前电脑能读取的路径。

```text
使用 ListingFlow 生成商品文案。
SKU：【填写 SKU】
站点：【美国站 / 英国站 / 澳大利亚站 / 德国站】
资料目录：【填写产品资料目录】
允许读取该目录及其子文件夹。
请自动核对、调研、生成和审核，
交付完整文案、文案.xlsx 和自查.xlsx。
```

可选补充：重点卖点、目标人群、语气、参考文案、竞品链接、关键词、避开内容、输出目录。没有时直接省略，不需要准备英文旧稿或关键词文件。

## 收到结果后

先看 `自查.xlsx` 的“审核结论”和待办，再复制 `文案.xlsx` 中的内容。草稿不等于可直接发布；“没有命中词库”不等于事实、权利和平台要求全部通过。

## 遇到提示怎么办

| 提示 | 处理方式 |
| --- | --- |
| 资料无法读取 | 确认目录在当前电脑可访问，并检查是否需要先同步云盘文件 |
| 产品型号或关键参数不一致 | 集中确认助手列出的具体问题 |
| eBay 需要登录或验证 | 在浏览器中自行完成；不要在聊天里发送密码、验证码或 Cookie |
| 实时关键词未取得 | 查看具体渠道和原因；受限渠道不能当作已验证，仍可获得标注范围的草稿 |
| 环境能力不足 | 将助手给出的简短诊断交给发布负责人，不需要自行安装 Python 库 |

插件不附带产品资料或 eBay 登录态。运行环境和跨电脑验收由发布负责人处理，详见 [发布与验收](docs/publishing.md)。
